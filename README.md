This repo has all my weekly assignments from the Internnova AI & ML program. Each week covers a different topic — starting from Python basics and going all the way to Machine Learning.

## Weekly Progress

### Week 1 — Introduction to AI & Python
- What is AI, types of AI (ANI, AGI, ASI)
- Python basics
- Simple chatbot and CSV handling

### Week 2 — Python for AI & Data Handling
- NumPy fundamentals (arrays, indexing, math operations)
- Pandas and dataset handling (load, filter, explore)
- Data cleaning (missing values, duplicates, wrong types)
- Data visualization using Matplotlib (bar, line, histogram, scatter)
- Mini project: Student Performance Data Analysis

### Week 3 — Introduction to Machine Learning
- ML concepts: supervised, unsupervised, classification, regression
- Dataset preparation and feature selection
- Train-test split and feature scaling (StandardScaler)
- Logistic Regression model training and evaluation
- Mini project: Student Performance Prediction (PASS/FAIL)
